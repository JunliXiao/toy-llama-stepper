本文件定義 **Toy Llama Block Stepper** 的核心價值主張、系統架構不變量（Invariants）與設計邊界。所有未來的功能擴充、視覺化重構或模型新增，皆須在不違反以下原則的前提下進行。

---

## 1. 設計哲學與目標（Design Philosophy）

* **降低數學門檻，普及機制可解釋性（Mechanistic Interpretability）**：作為一項互動式學習工具，讓數學或線性代數背景不深的族群，也能透過直觀的數值流動與幾何變化，理解現代大型語言模型（LLM）內部的特徵提取與資訊路由機制。
* **輕巧直覺的鍵盤操控與肌肉記憶**：將模型探索過程設計為符合直覺的鍵盤互動體驗，讓使用者在反覆切換步驟、層級與注意力頭的過程中，自然建立對 Transformer 空間結構的肌肉記憶。
* **透明且規模適中的計算過程展開**：拒絕將神經網路視為不可拆解的黑箱；透過適中且人類可一眼掌握的張量尺度，將每一步矩陣運算完整攤平，並允許隨時下探至最基礎的算術細節。
* **零建置與跨環境立即可用**：堅持純原生前端技術棧，無需任何編譯、打包或後端環境，確保專案無論在本機檔案系統直接開啟，或部署於靜態託管平台（如 GitHub Pages），皆能零門檻即時運行。
* **無狀態的沙盒體驗**：將工具定位為純粹的「互動式計算白板」，不保存任何使用者操作紀錄或修改狀態，讓學習者可以無心理負擔地任意修改輸入數值進行實驗，重新載入即可回到乾淨起點。

---

## 2. 核心架構不變量（Architectural Invariants）

* **零建置與本機檔案協定（`file://`）相容性**：專案必須保持純原生靜態架構，不依賴打包工具或前端框架；所有程式碼模組、數學排版引擎與預設模型資產，皆必須能透過靜態標籤直接載入，嚴禁使用在 `file://` 協定下會觸發跨來源限制（CORS）的載入方式（如原生 ES Modules 模組匯入或執行期非同步請求本地檔案）。
* **無狀態與確定性前向傳播**：系統嚴禁將使用者的輸入修改、當前步驟或介面設定寫入瀏覽器本地儲存空間（如 `localStorage`、`IndexedDB` 或 Cookie）；在相同模型權重與相同輸入設定（輸入矩陣、序列長度、隨機種子）下，任何時間與環境開啟都必須產出完全一致的數學結果與視覺呈現。
* **白箱算子與微觀算術可展開性**：前向推論過程嚴禁為了執行效能進行算子融合（Operator Fusion）；每一個數學轉換都必須保留獨立的中間步驟與完整張量，且任意輸出矩陣的單一元素，都必須能向下展開為初等四則運算（逐項乘加或歸一化細節）。
* **單屏可視性與人類認知尺度**：模型隱藏層維度、注意力頭數與序列長度必須嚴格維持在人類工作記憶與單一螢幕可完整掃視的極小規模內，不引入虛擬捲動（Virtual Scroll）或矩陣數值折疊省略，確保數值分布與正負極性一目了然。
* **模型權重與推論輸入分離**：預載的模型架構與權重資產必須與推論輸入完全解耦；使用者在畫面上即時編輯輸入矩陣或調整隨機種子時，只能觸發純函數式的確定性前向重算，絕不可回頭污染或修改當前載入的模型權重。
* **跨層步驟結構對稱性**：每一層 Transformer Block 的算子順序、步驟數量與命名定義必須保持嚴格對稱，確保使用者透過鍵盤進行「層內推進」、「跨層同階段對照」與「注意力頭切換」的三維空間導航時，位置對應永遠精準、不破壞操作直覺。
* **輸入優先權與非侵入式快捷鍵邊界**：全域快捷鍵（如 `←`/`→`、`↑`/`↓`、`Q`/`W`、`[`/`]`）必須嚴格退讓給原生文字輸入與作業系統／瀏覽器控制權，系統必須滿足三項邊界條件：
  1. **表單焦點讓渡**：當焦點位於任何可編輯元件（如 `X₀` 矩陣輸入格或參數欄位）時，全域快捷鍵完全停用。
  2. **輸入法組字隔離（IME Safety）**：在中文或日文等輸入法處於組字狀態（`isComposing`）時，嚴禁攔截任何按鍵事件，避免干擾選字與上字流程。
  3. **修飾鍵與物理鍵位隔離**：單鍵快捷鍵必須綁定物理鍵位（`e.code`）而非字元輸出（`e.key`），並檢查無修飾鍵（`Ctrl`、`Meta`、`Alt`），確保在 macOS 等多語系輸入法切換下依然穩定觸發，且絕不劫持瀏覽器或作業系統的原生組合鍵（如 `Cmd+W`、`Cmd+R`、`Ctrl+Tab`）。
* **介面文案與資料運算分離**：步驟標題、數學公式說明與介面操作字串必須與核心數值運算引擎（`model.js`）完全分離，確保未來擴充多國語系時無需重複或改動任何數學邏輯。

## 3. 明確不做什麼（Non-Goals）

* **不做反向傳播與模型訓練**：本工具專注於推論期（Inference）的前向資訊流動與已知機制的視覺化拆解，不引入損失函數、梯度計算、反向傳播或權重更新流程。
* **不引入建置管線與現代前端框架**：拒絕引入任何需要套件管理器安裝依賴或透過編譯器轉譯的框架與工具鏈，以維持程式碼的長期可讀性、零維護成本與開箱即用特性。
* **不做使用者狀態的本地或雲端持久化**：不設計帳號系統、實驗進度存檔或瀏覽器快取還原機制；重新整理頁面即代表無條件重置為乾淨的初始狀態。
* **不追求大規模參數與真實詞表推論**：不載入真實大型語言模型的權重檔案，也不將張量維度擴大至需要硬體加速或分頁載入的規模，避免為了擬真而犧牲白箱計算的透明度與認知負荷控制。
* **不劫持瀏覽器原生行為與自訂按鍵映射系統**：不覆寫瀏覽器預設的系統級組合鍵（如分頁切換、重新整理、頁面縮放），也不引入複雜的自訂快捷鍵設定面板，維持零設定、開箱即用的輕量操作體驗。
